# Data instructions

The notebook loads `telecom_customer_churn.csv` from the same folder as the notebook. The CSV is not included in this package.

The original input has 7,043 customer records and 38 columns. It includes customer details, contracts, service use, charges, customer status, and reported churn reasons. The notebook describes the account status as the end of Q2 2022.

Use the original CSV used for this project, rather than another telecom churn dataset with a similar name. The supplied notebook does not identify the original publisher or dataset URL. Add that citation here once confirmed, and check the dataset's terms before sharing the CSV publicly.

Place the CSV beside `telecom_customer_churn_prediction.ipynb` before running it. The `.gitignore` excludes CSV files from Git uploads by default.
